# Pokedex App - UIKit

Este é um aplicativo que foi feito em uma mentoria atravez do ifce para desenvolvedores ios para desenvolver habilidades com UIKit e desenvolvimento de testes unitarios com XCTest 

## Tecnologias Utilizadas

- Swift
- UIKit
- Auto Layout com View Code
- Arquitetura MVVM
- Test unitarios com XCTest
- Consumo de ApiRestfull 

---

## Funcionalidades

- Tela inicial com funcionalidade de listar pokemons consumindo apiRestFull
- Tela de detalhes de pokemons mostrando as caracteristicas de cada pokemon

---

## 🧠 Objetivo do Projeto
- Desenvolver com UIKit viewCode
- Consumo de api
- Entender ciclo de vida da activity
- Como implementar o padrao mvvm
- Desenvolver tests unitarios com XCTest
- Como reaproveita codigo
